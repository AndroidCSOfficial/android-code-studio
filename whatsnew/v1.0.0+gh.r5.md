## Full Changelog

### New Changes & Improvements 

- Removed AGP restrictions allowing all newer agps to be used without limitations
- Supports for larger projects without throwing OOM ( OutOfMemory Exception )

---

## 🐛 Bug Fixes

- Fixed project setup failing due to how some SDK installations format version numbers
- Fixed a crash on activity relaunch (`Required value was null` in `MainActivity`) caused by system bar insets being applied before the view binding was ready (https://github.com/AndroidCSOfficial/android-code-studio/issues/290)
- Fixed a crash on app restart while a chat/AI panel was previously open, caused by the project path being read before it was restored (`Cannot get project directory. Path has not been set.`) (https://github.com/AndroidCSOfficial/android-code-studio/issues/320)
- Fixed a crash in `MemoryUsageWatcher.readUsages` (`NullPointerException`) caused by a race condition where a process could be unwatched between two lookups in the same memory-reading pass (https://github.com/AndroidCSOfficial/android-code-studio/issues/315)
